Работа содержит end-to-end (сквозные) тесты для проверки развертывания инфраструктуры WordPress в Yandex Cloud с использованием Terraform. Тест автоматически развертывает инфраструктуру, выполняет проверки и затем удаляет ресурсы.

Структура теста
1. Импорты и флаги командной строки
terraform и test-structure - библиотеки для работы с Terraform в тестах

ssh - для проверки SSH соединения с виртуальными машинами

folder и sshKeyPath - флаги для передачи параметров при запуске теста

2. Три этапа выполнения теста
Этап 1: Setup (Настройка и развертывание)
go
test_structure.RunTestStage(t, "setup", func() { ... })
Инициализирует Terraform в указанной директории

Применяет конфигурацию Terraform с передачей переменных

Сохраняет состояние для использования в следующих этапах

Этап 2: Validate (Валидация инфраструктуры)
go
test_structure.RunTestStage(t, "validate", func() { ... })
Содержит четыре основных проверки:

2.1 Проверка балансировщика нагрузки:

Получает внешние IP-адреса балансировщика из вывода Terraform

Проверяет, что адреса существуют

2.2 Проверка SSH соединения:

Получает публичные IP-адреса виртуальных машин

Устанавливает SSH соединение с первой доступной машиной

Выполняет команду ping для проверки сетевой связности

2.3 Проверка информации о базе данных:

Получает конфиденциальные данные о базе данных (имя БД и пользователя)

Проверяет, что информация доступна

Этап 3: Teardown (Очистка)
go
test_structure.RunTestStage(t, "teardown", func() { ... })
Удаляет все созданные ресурсы через terraform destroy

Обеспечивает отсутствие утечек ресурсов после тестов

Ключевые особенности
Безопасность
Для работы с SSH используется приватный ключ

Данные базы данных помечены как sensitive = true в outputs.tf

SSH ключ передается через флаги командной строки

Надежность
Использует test-structure для сохранения состояния между этапами

Включает отложенные вызовы defer для закрытия SSH соединений

Имеет таймаут 30 минут для длительных операций

Воспроизводимость
Все параметры передаются через флаги

Автоматически создает и удаляет инфраструктуру

Не оставляет ресурсов после завершения

Запуск теста
bash
go test -v ./ -timeout 30m \
  -folder 'b1g0dfnts2jube1lose6' \
  -ssh-key-pass 'C:/Users/aivanov/.ssh/id_ed25519_aivanovvscode'
Примечание: Для корректной работы нужно указать путь к приватному ключу (без расширения .pub), так как для SSH аутентификации требуется именно приватный ключ.

Выходные данные
Тест проверяет соответствие между:

Конфигурацией в outputs.tf (IP-адреса, информация о БД)

Реально созданными ресурсами в Yandex Cloud

Сетевыми возможностями развернутых инстансов

Этот подход обеспечивает полную проверку работоспособности инфраструктуры перед использованием в production.
